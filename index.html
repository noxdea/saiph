Fail closed, everywhere.

Saiph reports availability only after a native capability probe succeeds. If restriction setup fails, the child exits instead of silently running unsandboxed.

Native enforcement

Seatbelt on macOS, namespaces with Landlock and seccomp on Linux, and AppContainer on Windows.

Immutable policy

Allow only specific paths, network access, descendant processes, and environment names.

Shell-free launch

Spawn argument arrays with normal Ruby redirections while keeping policy transfer private.

Draw the boundary.

Describe the minimum capability set, probe the backend, then launch.

Ruby
$ bundle add saiph

policy = Saiph::Policy.new(
  read_paths: ["/app/plugin.rb"],
  write_paths: ["/app/tmp"],
  network: false, exec: false,
  env: ["LANG"]
)
Saiph.spawn([RbConfig.ruby, "plugin.rb"], policy:)
